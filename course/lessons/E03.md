# E03 · Java basics: reading the crforge facade

**Time:** about 6 hours · **You will be able to:** read Java types and methods, trace the Python bridge, and check unit conversions.

## Why this matters for ClashBot

The Icebow decision code is written largely in Python, but the crforge simulator is Java. The file `scratchpad/gauntlet/L74/crforge/facade/CfCore.java` provides the connection. Understanding a few declarations helps you follow where a seed, a deck, or a tower value goes.

The Python side is `pipeline/crforge_core.py`. It adapts crforge to an interface already used for RoyaleSim. An **interface** is an agreed set of operations and data meanings. Matching operation names is insufficient if one engine uses a different coordinate scale. We will read the bridge and practise small conversions without starting Java or a simulator.

## 1. Static types

A **type** describes what kind of value is allowed. In Python, a variable can be rebound to different kinds of values. Java checks declared types before a program runs. This is **static typing**: many inconsistencies are detected while preparing the program.

```java
int elixir = 8;
boolean affordable = elixir >= 6;
System.out.println(affordable);
```

**Output:** `true`, when these statements are placed inside a Java method.

The type int stores a bounded whole number. Boolean stores true or false. Java spells those values in lowercase. String, with a capital S, stores text. A semicolon ends a statement. Curly braces group statements into a block.

Java int is normally a signed 32-bit integer. Its range is finite, unlike Python integers that can grow as memory permits. None of our tiny examples approach the limit, but simulator coordinate and tick calculations should still have documented ranges.

```python
elixir = 8
affordable = elixir >= 6
print(affordable)
```

**Output:** `True`.

Compare the languages line by line. The logic is unchanged; declaration syntax, statement endings, and boolean display differ. The exercise runner uses this Python version so the concept is testable without a Java installation.

## 2. Classes, fields, and methods

A **class** defines a kind of object, as in B09. A **field** stores data inside a Java object or class. A **method** is a function belonging to a class. A **constructor** prepares a new object and has the same name as its class.

```java
class Tower {
    int hp;
    Tower(int initialHp) { hp = initialHp; }
    int remaining(int damage) { return Math.max(0, hp - damage); }
}
```

**Output:** none; this declares a class.

The first line names the class. The second declares an integer field. The constructor receives initialHp and stores it in hp. The method receives damage and returns an integer. Math.max chooses the larger of zero and the remaining hit points, preventing a negative answer.

Creating a Tower alone does not print anything. Calling remaining also does not print unless the caller prints its result. This is the same distinction between return and print from B05.

```python
class Tower:
    def __init__(self, hp):
        self.hp = hp
    def remaining(self, damage):
        return max(0, self.hp - damage)

tower = Tower(100)
print(tower.remaining(30))
print(tower.hp)
```

**Output:** `70` then `100`.

The method calculates a value but does not assign it back to hp. When reading unfamiliar code, identify both the returned value and any changed state. A method named step is likely to change a simulator, but its name alone is not proof.

## 3. Reading modifiers

A **modifier** changes how a declaration may be used. Public means accessible to other code. Static means the member belongs to the class rather than an individual object. Final prevents reassignment of a variable; on a class it prevents subclassing.

```java
public static final int K = 18;
```

**Output:** none; this declares a class constant when placed in a class.

Read it as “a public class-level integer whose assigned value cannot be replaced.” Do not infer that every final object is deeply immutable. A final reference to a collection can still point to a collection whose contents change.

A **return type** appears before a method's name. Void means no value is returned. In a signature such as `public void reset(int seed)`, reset is a public method receiving one integer and returning nothing. Its useful effect is changing the object's state.

We cover inheritance and richer language design only as needed in later source reading. For this lesson, locate names, types, inputs, outputs, and assignments. You do not need to reproduce the entire engine class hierarchy.

## 4. Arrays and dictionaries across languages

A Java **array** stores a fixed-length sequence. `int[]` means an integer array; `int[][]` means an array of integer arrays. The expression new int[2][8] allocates two rows of eight integers, initially zero.

```python
levels = [[0 for _ in range(8)] for _ in range(2)]
levels[0][0] = 16
print(len(levels), len(levels[0]), levels[1][0])
```

**Output:** `2 8 0`.

The Python comprehension creates separate inner lists. Repeating the same inner list twice would cause both sides to share state accidentally. Independence matters when comparing two simulator players or loading separate forks.

Java HashMap is a dictionary-like collection. **Generic type arguments** in angle brackets describe the allowed entry types. `HashMap<String, Integer>` maps strings to boxed integer objects. For reading this facade, think “names mapped to counts.” We do not need the implementation details of boxing.

A Java lookup may return null for a missing entry. Null means no referenced object; Python often uses None for the same purpose. A missing body-name mapping must be handled explicitly rather than treated as a valid card ID.

## 5. Compiling and running

A **compiler** translates source code into another form and checks many language rules. The javac program compiles Java source into **bytecode**, instructions for the Java Virtual Machine. The **JVM** executes that bytecode. A **JAR** packages compiled classes and other resources.

This complete toy class illustrates the structure, without requiring you to create a file:

```java
public class ElixirDemo {
    public static void main(String[] args) {
        int available = 8;
        System.out.println(available - 6);
    }
}
```

**Output:** `2`, if compiled and run.

Main is the conventional entry method. Its String array contains command-line arguments. A source file for this public class would be named ElixirDemo.java. The command javac ElixirDemo.java would produce a compiled class; java ElixirDemo would run it. Those commands are explanatory, not course exercises.

The **classpath** tells the JVM where to find classes and libraries. A missing class may indicate an incomplete classpath, not an error in game logic. Distinguish setup failure from a valid simulation that produces an unexpected match outcome.

## 6. Python calling Java

A **bridge** lets one language call another. JPype is the bridge used here to access Java from Python within the same process. This is different from sending text to a separately launched command.

The bridge needs a JVM, compiled facade classes, and the engine libraries. It also converts values such as strings and integer arrays. This lesson reads the setup as text; importing the real module could trigger environment setup and is unnecessary.

```python
java_arguments = {"seed": 7, "levels": [16] * 8}
print(java_arguments["seed"], len(java_arguments["levels"]))
```

**Output:** `7 8`.

This dictionary is a teaching model of inputs, not a JPype call. Verify shapes and types before blaming the engine. A seven-card array where eight are expected is an interface problem even if every individual element is a valid integer.

## 7. Unit conversions are part of correctness

A **unit** states what a number measures. The facade converts crforge position units to RoyaleSim subtiles by multiplying by 18. A value without its unit is ambiguous.

```python
crforge_x = 1000
royalesim_x = crforge_x * 18
print(royalesim_x)
print(royalesim_x // 18)
```

**Output:** `18000` and `1000`.

The inverse integer conversion is exact here because the value is divisible by 18. If it is not divisible, silently using integer division discards information. Our exercise requires divisibility and raises ValueError otherwise.

This arithmetic does not establish that all engine behaviour matches. It checks one interface convention. Deployment delay, tower selection, and snapshots have their own contracts. A **snapshot** records state at a moment; loading one should not accidentally mutate the original snapshot while exploring a different move.

## In the real project

From `scratchpad/gauntlet/L74/crforge/facade/CfCore.java`:

```java
public final class CfCore {
  public static final int K = 18, NONE = -1;
```

**Output:** none; this is a declaration excerpt.

Line one declares the public facade class and prevents subclassing. Line two declares two integer constants. K records the position scale factor. NONE supplies a sentinel, a special value representing absence. The excerpt opens a class; it is intentionally not a complete Java program.

From the same file:

```java
    int[][] levels = new int[2][8];
    int[][] deckIds = new int[2][8];
    int[][] forms = new int[2][8];
```

**Output:** none.

Each line allocates a separate two-by-eight integer array. The arrays represent card levels, deck identities, and forms respectively. The shared shape expresses two sides with eight deck slots, but the meanings differ. Equal shapes do not make the arrays interchangeable.

From `pipeline/crforge_core.py`:

```python
K = 18                         # RoyaleSim subtiles per crforge game unit
DELAY = 20                     # crforge Standard1v1Battle.PLAY_DELAY_TICKS
LEVEL = 16
```

**Output:** none; three constants are assigned.

The first line repeats the conversion contract on the Python side. The second records command delay in ticks. The third records a level default in this source. These are source facts, not permission to assume every run uses identical configuration.

## Common mistakes

- Thinking Java declarations print their values.
- Confusing static members with per-match state.
- Treating a missing mapping as card zero.
- Passing a value in the wrong coordinate unit.
- Importing the bridge just to inspect source text.
