## 1. The replay pipeline

An **extractor** turns observed logs into a candidate command sequence and initial setup. A **reconstruction** is the resulting proposed account of what happened. The replay pipeline is observation, extraction, engine execution, then comparison. Each stage can introduce errors. An omitted ability command may look like a missing engine mechanic even if the engine would simulate it correctly when supplied. Conversely, a well-recovered command does not prove the engine's rule is correct. Keep separate records of input completeness and output agreement. An unknown match outcome remains unknown; exactness is a different measurement from win rate.

```python
pipeline=['observe','extract','replay','compare']
print(' -> '.join(pipeline))
inputs={'deck':True,'commands':True,'seed':False}
print(all(inputs.values()))
```

**Output:** `observe -> extract -> replay -> compare` and `False`.

The dictionary models evidence availability, not game state. A missing seed might matter only for some command sequences, but that requires a justified RNG argument. Do not infer irrelevance merely because one replay looks similar.

## 2. Align ticks before objects

An **alignment** associates observations representing the same instant. The SME source defines observation tick g as state before step g runs. A command executed at R first appears at R+1 in that convention. Our toy comparator receives dictionaries indexed by tick and compares matching entries. A missing tick must remain a missing observation, not a zero-health frame. A one-tick shift can move every object enough to produce a large mismatch count while the engine trajectory itself is otherwise correct.

```python
run_tick=197
first_visible=run_tick+1
print(first_visible)
live={0:100,2:96}
sim={0:100,1:98,2:96}
print(sorted(set(live)&set(sim)))
print(sorted(set(sim)-set(live)))
```

**Output:** `198`, `[0, 2]`, and `[1]`.

The intersection identifies comparable ticks. The difference identifies a missing live observation. Reporting only the intersection's perfect agreement would hide the gap. Temporal alignment can be investigated with nearby frames, but shifting labels after seeing outcomes must not silently change a frozen exactness metric.

## 3. Canonicalize without losing information

A **canonical representation** puts equivalent data into one consistent form. Object lists may arrive in different orders, so sort tuples of relevant fields before comparing. A **multiset** preserves how many times each value occurs, unlike a set. A sorted list of tuples acts as a simple multiset representation for our toy objects. We compare side,x,y,hp. If two units share all four fields, both entries must remain. This limited comparator does not check identity or every mechanic; explain the omitted fields instead of claiming full state equivalence.

```python
objects=[{'side':0,'x':4,'y':20,'hp':10},
         {'side':0,'x':4,'y':20,'hp':10}]
canon=sorted((u['side'],u['x'],u['y'],u['hp']) for u in objects)
print(canon)
print(len(canon))
```

**Output:** `[(0, 4, 20, 10), (0, 4, 20, 10)]` and `2`.

Turning canon into a set would erase one unit. Sorting changes only display order; it does not allow a coordinate or health tolerance. The real SME comparison includes towers, projectiles, effects, elixir, hands, and queues, while noting that card identity has limitations. Our exercise is explicitly a smaller comparator.

## 4. Find the earliest divergence

A **divergence** is a disagreement between aligned trajectories. The first observed divergence is often more useful than the largest final error: one missed command can create hundreds of later differences. Iterate through the union of observed tick labels in ascending order. If a tick is missing on either side, report it as the first mismatch under our strict trace contract. Otherwise compare canonical objects. A missing frame is an observation issue, not automatically proof that engine rules differ. The report should preserve the difference between the detection result and its causal explanation.

```python
live={0:100,1:98,2:96}
sim={0:100,1:99,2:97}
first=None
for t in sorted(set(live)|set(sim)):
    if live.get(t)!=sim.get(t):
        first=t
        break
print(first)
```

**Output:** `1`.

break exits the loop once the earliest discrepancy is found. This toy example compares scalar health values. The exercise compares whole canonical object lists and handles missing tick membership explicitly. A counterexample with one health point changed tests whether the comparator can detect the smallest intended defect.

## 5. Torn reads and bounded goals

A **torn read** samples parts of state across an update instead of at one consistent instant. Some units may match tick t and others tick t+1. That pattern can explain a mismatch without proving the engine wrong, but it requires evidence. The early SME pilot reports 2065 of 2068 frames exact for candidate A, with the remaining cases investigated as timing problems. Later sections describe D1 as at least 45 of 50, or 90%, and D2 as a .98 lower-bound target; their precise population and exception rules matter. The broader fresh gates were not met in the inspected record.

```python
strict_exact,total=2065,2068
print(round(strict_exact/total,5))
print(strict_exact==total)
print({'strict_failures':total-strict_exact,'diagnosis':'requires frame evidence'})
```

**Output:** `0.99855`, `False`, and a dictionary reporting three strict failures.

The exactness fraction is a frame metric, not a win rate or match-level pass rate. Do not substitute thousands of correlated frames for independent matches in a confidence interval. The syllabus's observation-gap emphasis is supported by specific diagnoses, not a license to classify every future failure that way. Engine, extractor, and unresolved causes all remain possible.

## Guided practice and review

### Practice 1: Canonical object list

Write canonical(objects) returning a sorted list of (side,x,y,hp) tuples, preserving duplicates. Example: two identical units remain two tuples.

Canonicalization removes irrelevant order only. Every field retained in the tuple remains part of the exact comparison.

### Practice 2: Find the first strict mismatch

Write first_difference(live,sim) for tick-to-list-of-tuples dictionaries. Return earliest missing or unequal tick, else None. Compare sorted lists so ordering is irrelevant. Example: identical tick 0 but different tick 2 returns 2.

Returning None means no mismatch under this supplied trace contract. It does not claim omitted state components or unrecorded ticks were validated.

### Practice 3: Report coverage and agreement

Write coverage(live,sim) returning {'compared':intersection size,'exact':equal values on shared ticks,'missing':symmetric-difference size}. Example: live={0:1},sim={0:1,1:2} gives 1,1,1.

The symmetric difference syntax is introduced here. It counts missing labels in either trace, which is different from disagreement at a shared label.

### Practice 4: Detect a toy mixed-time signature

Write mixed(observed,before,after) for equal-length numeric lists. Return True only if every observed value matches its corresponding before or after value, at least one matches only before, and at least one matches only after. Example: [1,4] from before=[1,2],after=[3,4] is True.

This is a diagnostic signature, not proof of cause. Real object matching requires identity, timing, and missing-object analysis beyond corresponding numeric positions.

### Practice 5: A planted health defect

Write inject_hp(objects,index,delta) returning a deep-copied list with only the selected object's hp changed. Example: delta=-1 plants a one-HP mismatch without editing the original.

A planted defect verifies sensitivity. Keep the unmodified control alongside it so the comparator must both accept matching data and reject the deliberate change.

## Common mistakes

- Comparing neighboring ticks as if they were the same instant.
- Sorting objects into a set and losing duplicate units.
- Ignoring missing frames and reporting all compared frames as all frames.
- Calling every mismatch an engine bug before checking extraction.
- Using a tolerance that hides a planted one-HP error.
