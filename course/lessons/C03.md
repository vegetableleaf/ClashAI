## 1. The figure and its axes

**matplotlib** is a plotting package. Its pyplot module provides figure creation and saving tools. A **Figure** is the whole image; an **Axes** is a plotting area inside it. The plural-looking word Axes names one object. An **axis** is one scale, such as horizontal match number or vertical win rate. plt.subplots returns a figure and an axes object. Keep both names so you can style the axes and save the figure explicitly. We print the plotted data to show exactly what the example has drawn rather than relying on a graphical window.

```python
import matplotlib.pyplot as plt
fig, ax = plt.subplots()
line, = ax.plot([1,2,3], [0.4,0.5,0.6])
print(line.get_ydata().tolist())
plt.close(fig)
```

**Output:** `[0.4, 0.5, 0.6]`; a line is created in memory and then closed.

The comma after line unpacks a one-element list. plot returns a list because it can draw several lines. A line joins neighboring points, suggesting an ordered sequence. Use it for consecutive match windows, not unrelated opponent deck categories. Closing removes the figure from pyplot's active figures; the example deliberately does not open a window.

## 2. Make labels do useful work

A chart needs units, a denominator, and enough context to avoid an exaggerated claim. Use set_xlabel and set_ylabel for the axes, set_title for a short description, and set_ylim for a declared vertical range. A fraction of 0.6 is 60 percent, but changing the label alone does not convert the data. Starting a rate axis at zero makes absolute differences easy to judge. A zoomed axis can be useful for small changes if it is clearly labeled; never hide the choice. Include known-game counts beside the figure in a real report.

```python
import matplotlib.pyplot as plt
fig, ax = plt.subplots()
ax.plot([1,2], [50,60])
ax.set_xlabel('Decisive match number')
ax.set_ylabel('Win rate (%)')
ax.set_ylim(0,100)
print(ax.get_ylabel())
print(tuple(float(value) for value in ax.get_ylim()))
plt.close(fig)
```

**Output:** `Win rate (%)` and `(0.0, 100.0)`.

The values are already percentages in this example. The horizontal axis says decisive match number because unknowns and draws have been removed by the declared C02 rule. If you plotted calendar days instead, use dates and say how days with no decisive games are displayed. A title should describe the metric rather than declare victory.

## 3. Bars compare categories

A **bar chart** displays a value for each category. A bar's height represents the measurement; its width usually has no statistical meaning. For a data-quality chart, categories WIN, LOSS, DRAW, and unknown are clearer than one win-rate line. This display answers a different question from performance: how much usable evidence do we have? A period with fewer known outcomes may need investigation even if its known-game win rate looks excellent. Preserve an explicit order instead of allowing alphabetical sorting to change the arrangement between reports.

```python
import matplotlib.pyplot as plt
fig, ax = plt.subplots()
bars = ax.bar(['WIN','LOSS','DRAW','unknown'], [3,2,1,4])
ax.set_ylabel('Recorded matches')
print([int(b.get_height()) for b in bars])
plt.close(fig)
```

**Output:** `[3, 2, 1, 4]`.

The heights add to ten recorded matches. The decisive win rate is three fifths, not three tenths. The bar chart therefore complements rather than replaces that metric. A real report should show both the rate and exclusions. Different unknown proportions can change how much trust you place in a period comparison.

## 4. Histograms show distributions

A **distribution** describes how values are spread out. A **histogram** groups numerical observations into **bins**, intervals of values, and counts how many fall into each interval. Use it for toy decision latency, not for named outcome categories. Choosing wider bins hides detail; choosing very narrow bins makes small samples look noisy. The last bin includes its right edge in NumPy and matplotlib's standard histogram convention. Other bins include the left edge and exclude the right edge. Define bins explicitly in an exercise so the expected counts are unambiguous.

```python
import matplotlib.pyplot as plt
fig, ax = plt.subplots()
counts, edges, patches = ax.hist([10,20,30,40], bins=[0,25,50])
print(counts.tolist())
print(edges.tolist())
plt.close(fig)
```

**Output:** `[2.0, 2.0]` and `[0.0, 25.0, 50.0]`.

The first bin contains 10 and 20; the second contains 30 and 40. These are invented milliseconds, not measured live latency. A mean alone would miss a long slow tail, so histograms can help diagnose why a few late decisions cause problems despite a reasonable average.

## 5. Rolling means and saved output

A **rolling mean** averages successive fixed-size windows. On decisive outcomes encoded as one for WIN and zero for LOSS, it estimates a local win fraction. Consecutive windows overlap, so their points are not independent experiments. Sort records first, remove unknowns and draws under the declared rule, and do not replace an incomplete first window with zero. A **headless backend** renders images without a graphical display. The exercise runner uses Agg. tempfile provides an automatically cleaned temporary directory; savefig writes the image there and close releases figure resources.

```python
import pandas as pd
import matplotlib.pyplot as plt
from pathlib import Path
from tempfile import TemporaryDirectory
rate = pd.Series([1,0,1,1]).rolling(3).mean()
fig, ax = plt.subplots()
ax.plot(rate.index, rate)
with TemporaryDirectory() as folder:
    path = Path(folder)/'rate.png'
    fig.savefig(path)
    print(path.stat().st_size > 0)
plt.close(fig)
```

**Output:** `True`; a PNG is saved temporarily, then removed when the context exits.

stat().st_size is the file length in bytes. A nonempty file is a useful smoke check but not proof that the right data was plotted. Tests should inspect the line values, labels, and limits too. The exercises follow that approach so a blank but valid PNG cannot satisfy the whole task.

## Common mistakes

- Connecting unsorted dates.
- Labeling a fraction as a percentage without multiplying by 100.
- Treating an undefined rolling value as zero.
- Using a histogram when categories need a bar chart.
- Calling show() in a headless exercise instead of saving.
