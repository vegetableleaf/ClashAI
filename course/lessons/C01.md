## 1. Arrays and types

**NumPy** is a package for numerical calculations. Its **ndarray** is a collection of values arranged into dimensions. A **dimension** is a direction of indexing: a sequence has one, while a board has rows and columns. The **shape** is a tuple of dimension lengths. The **dtype** describes the stored numerical type. Unlike a list, an array normally uses one shared dtype. Import NumPy as np, an ordinary short name for the module. Begin with three toy tower-health readings so you can inspect every entry.

```python
import numpy as np
hp = np.array([100, 80, 60], dtype=int)
print(hp.shape)
print(hp.dtype.kind)
print(hp[1])
```

**Output:** `(3,)`, `i`, and `80`.

The comma means a one-item tuple. The dtype kind i means signed integer without depending on machine width. Index 1 retrieves the second reading. Shape describes storage, not meaning: write down whether these positions mean different towers or successive measurements of one tower before computing changes.

## 2. Build an arena

A **cell** is one entry of a two-dimensional board. We choose board[y, x]: y selects a row and x selects a column. With 32 rows and 18 columns, y runs from 0 through 31, and x from 0 through 17. **Indexing** selects an element. A **slice** selects a range and excludes its stop value. NumPy uses a comma between dimensions inside brackets, whereas lists of lists use separate brackets.

```python
import numpy as np
board = np.zeros((32, 18), dtype=int)
board[20, 4] = 6
print(board.shape)
print(board[20, 3:6].tolist())
```

**Output:** `(32, 18)` and `[0, 6, 0]`.

zeros fills the board with zero. Here zero means no recorded deployment cost; six marks a toy X-Bow cost. It is not a complete game state. tolist converts an array into ordinary lists for display. The slice selects columns 3, 4, and 5. Negative indices are legal Python but should not be used to accept an off-board placement accidentally.

## 3. Vectorised arithmetic

**Vectorised arithmetic** applies an operation to an array without a Python loop around each element. A **scalar** is a single value such as 1.5. Adding a scalar applies that addition everywhere. This is the simplest form of **broadcasting**, NumPy's rules for matching sizes. It does not make incompatible measurements meaningful: adding tower health to elixir remains a mistake. Floating-point arrays preserve partial elixir. Assigning a fractional value into integer storage can discard its fractional part.

```python
import numpy as np
elixir = np.array([2.0, 8.5, 10.0])
after = np.minimum(elixir + 1.5, 10.0)
print(after.tolist())
print(elixir.tolist())
```

**Output:** `[3.5, 10.0, 10.0]` and `[2.0, 8.5, 10.0]`.

minimum selects the smaller value at each position and caps elixir. This expression returns a new result. It leaves the original unchanged, which is useful when explaining a simulator tick from before-and-after records. A different operation that assigns into the original would erase the earlier state.

## 4. Axes and reductions

A **reduction** combines values, for example sum or mean. An **axis** is a numbered dimension. In a two-dimensional table, axis 0 represents rows and axis 1 columns. Reducing along an axis removes it by combining its entries. Write input and output shapes before calculating: summing a (2, 3) table along axis 0 gives shape (3,), one total per column. This is more reliable than memorizing an arrow on a printed table.

```python
import numpy as np
a = np.array([[1, 2, 3], [4, 5, 6]])
print(a.sum(axis=0).tolist())
print(a.sum(axis=1).tolist())
print(a.mean())
```

**Output:** `[5, 7, 9]`, `[6, 15]`, and `3.5`.

The first column adds 1 and 4. The first row adds 1, 2, and 3. mean without an axis combines every cell. This makes sense for a board containing one measurement type. It does not make sense for a feature table whose columns mix health, seconds, and elixir.

## 5. Masks and broadcasting

A **Boolean mask** is an array of True and False values that selects entries. Comparing costs to current elixir creates one automatically. General broadcasting compares shapes from the right: each pair of sizes must be equal, or one must be 1. A length-three vector can therefore be added to every row of a table with three columns. A length-two vector cannot do the same just because the table has two rows.

```python
import numpy as np
costs = np.array([6, 4, 3, 1])
print(costs[costs <= 3].tolist())
a = np.array([[1, 2, 3], [4, 5, 6]])
print((a + np.array([10, 20, 30])).tolist())
```

**Output:** `[3, 1]` and `[[11, 22, 33], [14, 25, 36]]`.

The mask selects costs rather than names, so maintain the correspondence between arrays. Offsets have one entry per column. Before later machine-learning work, establish the habit of naming every dimension and checking a tiny example. If you cannot explain the first resulting cell, larger arrays will only hide the confusion.

## Common mistakes

- Swapping board[y, x] into board[x, y].
- Treating shape (32, 18) as 32 horizontal positions.
- Using integer storage for fractional elixir.
- Assuming broadcasting can align any two shapes.
